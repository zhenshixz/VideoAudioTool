# VideoAudioTool

一个基于 Flask 与 FFmpeg 的轻量视频、音频处理工具，支持 Windows 本地运行，也可部署到 Linux 服务器。

## 主要功能

- 调整视频或 MP3 音量，支持处理前预览。
- 提取视频中的 MP3，并精确输入开始、结束时间。
- 使用 MP3 替换视频指定区间的声音。
- 按规则重复填充 MP3，同时保留指定长度的原声。
- 修改电脑视频的创建时间。
- 通过 USB/ADB 将视频按指定事件时间写入 OPPO 手机相册。
- 调整已写入视频的 OPPO 相册显示时间：
  - 自动查找 `DCIM`、`Pictures`、`Movies` 下由本工具生成的视频。
  - 支持选择自建相册文件夹，例如 `DCIM/MyAlbums/3902_1`。
  - 选择视频后自动加载预览，确认内容再修改时间。
  - 先将手机原视频备份到电脑，再无重编码重写 MP4 时间元数据并刷新相册。
  - 原路径原文件名替换，不创建手机视频副本，画面和声音保持原码流。
  - 在电脑端保存原视频备份和时间修正日志。

## Windows 本地运行

运行前请安装：

- Python 3
- FFmpeg，并确保 `ffmpeg`、`ffprobe` 可在命令行使用

双击：

```text
run.bat
```

然后访问：

```text
http://127.0.0.1:5000
```

首次使用手机功能时，点击页面中的“安装手机连接组件”，并在 OPPO 手机上开启 USB 调试、允许电脑授权。手机连接和相册时间调整功能只能在本机使用。

## Linux 服务器部署

部署和自动更新说明见 [DEPLOY.md](DEPLOY.md)。手机 USB/ADB 功能不适用于云服务器，其余上传、预览和导出功能可正常部署。

## 注意事项

- 处理重要证据视频时，请另外保留未经处理的原文件。
- 相册时间由使用者填写，仅代表人工修正值；操作前请认真核对。
- 预览手机视频时只会在电脑生成临时缓存，切换视频或关闭页面后会自动清理。
